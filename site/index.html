Arquitectura

Cómo funciona en tres capas limpias

No te obliga a abandonar tu emulador de terminal ni a instalar un entorno pesado en Electron. Cada capa tiene una responsabilidad concreta y se puede inspeccionar por separado.

01 / VENTANA

Tu terminal de siempre

Corre dentro de Alacritty, Ghostty, WezTerm, Kitty o Windows Terminal. Incluye extras/alacritty.toml con option_as_alt = "OnlyLeft" para conservar @ # [ ] { } | \ ~ € en teclado español.

Alacritty 0.17 · Ghostty · WezTerm · WT
02 / MULTIPLEXOR

Servidor velm + OSC 133

Fork de herdr v0.9.5 con sockets propios (velm.sock), sesiones persistentes, sin comprobaciones de actualización ni descargas ocultas. Captura marcas OSC 133 para copiar o explicar cualquier comando.

~/.config/velm/config.toml · velm.sock
03 / HERRAMIENTAS

Suite term-* bajo demanda

Cuatro binarios Rust desacoplados con validación compartida en term-config. Todos arrancan con enabled = false: activas únicamente lo que necesitas en tu flujo diario.

term-ai · term-repos · term-sql · term-claude

Suite modular

Cuatro herramientas locales, cero sorpresas

Cada binario funciona tanto dentro de un panel de velm como desde cualquier shell, con salida TUI interactiva o --json para automatización.

Privacidad verificable

No te pedimos confianza: te damos los comandos para auditarlo

Ningún binario conecta con ningún destino externo que no hayas configurado o pedido en ese momento. Sin telemetría, sin update y sin descarga remota de plugins.

01 · Auditoría de dependencias cargo deny check

deny.toml bloquea reqwest, hyper, isahc, curl, surf, attohttpc y todo crate TLS (rustls, native-tls, openssl). Solo term-ai compila ureq sin TLS.

02 · Chequeo estático en CI term-ci.yml

En cada push y pull request se verifica que no exista std::net fuera de term-ai/term-sql ni llamadas a subprocesos curl, wget o nc fuera de tests.

03 · Monitorización en vivo ./scripts/net.sh

Inspecciona los procesos alacritty y velm con lsof -i -P -n cada 5 s durante 10 min (excluyendo shells hijas) y falla con código 1 si aparece una sola conexión de red.

Genera tu ~/.config/velm/config.toml
